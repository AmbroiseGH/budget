Règles de confidentialité

« Mes applications » regroupe des applications web personnelles (Budget, Habitudes, Journal, Maxilla) publiées sur ambroisegh.github.io/budget/.

Données

Les données saisies restent dans le stockage local de l'appareil. Aucun serveur ne les reçoit, et rien n'est partagé avec des tiers.

Google Drive

Si l'utilisateur connecte Google Drive, chaque application enregistre une copie de ses propres données dans le Drive de l'utilisateur, dans le dossier « applications ». L'accès demandé (drive.file) se limite aux fichiers créés par ces applications : elles ne lisent aucun autre fichier du Drive. Le jeton de connexion reste sur l'appareil. L'accès peut être retiré à tout moment sur myaccount.google.com/permissions.
